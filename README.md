# SWYNEX Data Preparation

## Project Overview

This project was completed as part of the SWYNEX Data Science Internship.

The objective of this task was to prepare and clean a public Netflix titles dataset by handling missing values, converting data types, validating important fields, checking duplicates, and creating a clean dataset ready for further analysis.

## Dataset

The project uses the **Netflix Titles** public dataset.

### Dataset Summary

- Total records: 8,807
- Total columns: 12
- Duplicate rows: 0
- Duplicate `show_id` values: 0
- Release year range: 1925–2021
- Invalid release years: 0
